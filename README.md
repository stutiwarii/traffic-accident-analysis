# Urban Traffic Accident & Road Safety Analysis

## Overview
Analysis of public road accident data to identify high-risk locations,
peak accident hours, and severity patterns.

## Dataset
Public traffic accident dataset adapted for analytical practice.

## Tools Used
- SQL
- Tableau
- Excel

## Key Insights
- Peak accident hours
- High-risk locations
- Accident severity distribution

## Dashboard
Tableau dashboard visualizing accident trends and hotspots.
